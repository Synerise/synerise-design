# ItemPicker

A field that picks one object from a list: a trigger, a dropdown with search, actions, Recent, paging and
a card for each row. The list (`ItemPickerList`) can be used on its own. It shows one of four variants,
chosen by what you pass as `items` and `sections`.

## Quick overview

- `import ItemPicker, { ItemPickerList } from '@synerise/ds-item-picker'`; render it inside `DSProvider`.
- Use the current API with `isNewVersion`. The props without it are the deprecated legacy picker.
- `items` decides how rows load: a fixed array, `{ items, limitPerSection }`, an `ItemLoaderConfig`
  (`loadItems`, paged) or a `MixedLoaderConfig` (`loadLevel`, the mixed list).
- `actions` add rows under "Actions" and under `/` in the search; `recents` adds a Recent group at the top.
- A row's `informationCardProps` opens its card on hover and on keyboard focus.

## Notes & tips

- **Mixed list:** Recent and the "Actions" list show only at the top level; while searching,
  matching actions are listed above the results. Search in is not supported in this mode.
- Search results in default rows are a flat list under "Results"; put the object's location in its card
  (`informationCardProps`).
- A folder with nothing the field can take should stay in the list, `disabled`, with its
  `disabledReason`, rather than disappear.
- `containerHeight="fitContent"` is for lists known up front (a fixed `items` array): one height, for the
  largest view the structure can show, that does not change as the user moves between sections, folders
  and search results, so the dropdown never repositions. A loaded list, including the list with
  folders, uses the preset height.
- Keyboard: ↑ ↓ move between the search and the rows, Enter picks, Esc clears the search and then closes,
  ⌘← goes back.
