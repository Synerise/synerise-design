# Select

A fully native (no Ant Design) select: a selector trigger plus a floating options
dropdown built on `@synerise/ds-dropdown` (floating-ui) and `@synerise/ds-list-item`,
wrapped in a `FormField` label/description/error layer. Supports single-select,
`multiple` (chip selector), `tags` (free-text), and in-selector search.

## Quick overview

- Import the default export: `import Select from '@synerise/ds-select';`
- **Options**: pass the `options` prop (`{ value, label?, disabled?, title? }[]`) or
  declarative `<Select.Option value="…">` children (read only when `options` is absent).
- **Controlled**: drive `value` + `onChange`; `defaultValue` for uncontrolled.
  `mode="multiple"`/`"tags"` use an array value.
- **Search**: set `showSearch` for an in-selector input. Client filtering uses
  `filterOption` (`true`/function) matched against `optionFilterProp`; set
  `filterOption={false}` and feed `options` from `onSearch` for remote search.
- **Dropdown**: positioned via `ds-dropdown`; `getPopupContainer`, `placement` and
  `dropdownMatchSelectWidth` control it. `dropdownRender` wraps the option menu.

## Multiple

`mode="multiple"` renders selected values as removable chips; Backspace removes the
last, and each chip reveals a remove control on hover.

<Canvas of={MultipleMode} />

### Chip overflow

`maxTagCount` caps how many chips render before the rest collapse into the
`maxTagPlaceholder` (`+ N` by default). `maxTagCount="responsive"` instead keeps the
chips on a single line and fits as many as the selector width allows, recomputing on
resize — so a select in a resizable panel never wraps to a second row.

<Canvas of={MaxTagCountResponsive} />

## Tags

`mode="tags"` lets the user create values by typing and pressing Enter (or a

box in styles, use `Select.styles.Selector` (the `.ds-select` element).

### `Select.Option`

Marker component (renders `null`); its `value`, children (→ label), `disabled` and
`title` (`ReactNode`) build the option list when the `options` prop is absent. antd
parity: `value` is optional and falls back to the element `key`, and callbacks expose
`option.key`. The antd `Select.OptGroup` is intentionally **not** reimplemented (no
real usage).

## Notes & tips

- **`ds-select-*` class hooks only** — the antd `.ant-select-*` classes are gone;
  target `.ds-select`, `.ds-select-selection-item`, `.ds-select-dropdown`, etc.
- **Remote search** — set `filterOption={false}` and update `options` from your
  `onSearch` handler; the component won't filter locally in that mode.
- **Keyboard navigation & ARIA** — Arrow / Home / End / Enter / Escape / Space (and
  Backspace to drop the last chip) are wired, with combobox / listbox
  `aria-activedescendant`.
