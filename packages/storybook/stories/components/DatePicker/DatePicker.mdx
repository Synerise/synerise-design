# DatePicker

Single-date picker with a dropdown calendar, optional time picker, quick-pick presets, and a formatted text input trigger.
Built on `react-day-picker` v7 and `date-fns` 2. Requires a `react-intl` `IntlProvider` in the component tree.

`value` takes a `Date` or an ISO 8601 string; `onApply` always hands back a `Date`.
With `timeZone` set, that `Date` is a `TZDate` carrying the resolved timezone.

`onApply` is **required** -- it fires when the user clicks Apply or selects a quick pick, and closes the dropdown.

## Timezone-Aware Mode

With `timeZone` set, `onApply` emits a `TZDate` — the real instant plus the zone it was read in — so the consumer chooses its own wire format instead of being handed one.
Set `timeZone={true}` to use the provider's timezone from `react-intl`, or pass an IANA timezone string (e.g. `"Asia/Tokyo"`) to override.
