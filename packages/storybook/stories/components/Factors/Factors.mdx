# Factors

A polymorphic input component that renders different input UIs based on a selected factor type,
with an optional type-switcher dropdown.

## Key features

- **10 built-in types:** text, number, date, dateRange, relativeDate, parameter, contextParameter, formula, dynamicKey, array
- **Type-switcher dropdown** lets users change the factor type at runtime (hide it with `withoutTypeSelector`)
- **`timeZone` prop** passed to both the Date and Date-range factor inputs for timezone-aware picking
- **Customisable** via `customFactorValueComponents` — override the rendered component for any built-in type
